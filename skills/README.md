# OpenCode Skills

This directory contains global OpenCode skills. OpenCode discovers skills from:

```text
~/.config/opencode/skills/<skill-name>/SKILL.md
```

## Matt Pocock Skills

Installed from `https://github.com/mattpocock/skills` at commit `b843cb5`.

The upstream repository groups skills under category folders such as `skills/engineering/diagnose`. OpenCode expects each skill to be one level under this directory, so the installed copy is flattened to `skills/diagnose`, `skills/tdd`, and so on.

Installed upstream plugin skills:

- `caveman`
- `diagnose`
- `grill-me`
- `grill-with-docs`
- `improve-codebase-architecture`
- `setup-matt-pocock-skills`
- `tdd`
- `to-issues`
- `to-prd`
- `triage`
- `write-a-skill`
- `zoom-out`

The upstream MIT license is stored in `MATTPOCOCK_SKILLS_LICENSE`.
